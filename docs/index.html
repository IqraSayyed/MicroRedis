Capabilities

Everything it does, beautifully.

Each layer of the database is built up phase by phase — from raw memory to durable networking.

⚡

In-Memory Storage

Lightning-fast key-value storage entirely in RAM, powered by native Python dictionaries.

🧵

Multi-Threaded

Handles many clients at once. Each connection runs on its own thread with threading.Lock() for safety.

🌐

Real TCP Networking

A genuine TCP socket server built with Python's socket library — clients connect over the network.

💾

AOF Persistence

Append-Only File logging means your data survives crashes and restarts intact.

🗣️

Redis-Style Commands

Understands SET, GET, and DEL with clean error handling and case-insensitive parsing.

🛡️

Race-Condition Safe

Locks protect shared state so concurrent writers never corrupt the store.

Syntax

Simple, familiar commands.

Just like the real thing — easy to remember, easy to use.

SET key value
Store a key-value pair
→ OK
GET key
Retrieve a value
→ value
DEL key
Delete a key
→ (integer) 1
QUIT
Disconnect from server
→ +OK Goodbye!
Get Started

Running it is trivial.

Clone, run, connect. No dependencies, no setup headaches.

1
Clone

git clone https://github.com/IqraSayyed/MicroRedis.git

2
Start

cd MicroRedis && python mini_redis.py

3
Connect

nc localhost 6379 or telnet localhost 6379

4
Use it

Try SET, GET and DEL commands!
