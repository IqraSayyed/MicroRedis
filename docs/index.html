MICROREDIS

A multi-threaded Redis clone built from scratch in Python

🐍 Python 3 ⚡ In-Memory 🧵 Multi-Threaded 💾 AOF Persistence 🌐 TCP Server

Try It Live

$ python mini_redis.py
[SERVER] MiniRedis server started on 127.0.0.1:6379
[SERVER] Multi-threaded mode: Each client gets its own thread
[SERVER] Waiting for client connections...

# From another terminal:
$ nc 127.0.0.1 6379
SET username Iqra → OK
GET username → Iqra
DEL username → (integer) 1
GET username → (nil)

What It Can Do

⚡

In-Memory Storage

Lightning-fast key-value storage entirely in RAM, powered by Python dictionaries.

🧵

Multi-Threaded

Handles many clients simultaneously. Each connection runs on its own thread with locks for safety.

🌐

TCP Networking

A real TCP socket server built with Python's socket library, so clients connect over the network.

💾

AOF Persistence

Append-Only File logging means your data survives crashes and restarts.

🗣️

Redis-Style Commands

Understands SET, GET, and DEL with proper error handling and case-insensitive parsing.

🛡️

Thread-Safe

Uses threading.Lock() to prevent race conditions when many clients write at once.

Run It Yourself

  1. Clone the repo: git clone https://github.com/IqraSayyed/MicroRedis.git
  2. Start the server: cd MicroRedis && python mini_redis.py
  3. Connect: nc 127.0.0.1 6379 (or telnet 127.0.0.1 6379)
  4. Use it: Try SET, GET, and DEL commands!

Architecture

MiniRedis → Core storage engine (thread-safe)
CommandParser → Parses & dispatches commands
PersistenceManager → AOF file logging & recovery
RedisServer → Multi-threaded TCP server

Built from scratch to learn database internals, networking, and system design.
